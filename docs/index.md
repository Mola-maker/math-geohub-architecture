Portable Agent Skills for building trustworthy AI-native visual editors.

The plugin packages three architecture capabilities derived from the public Math GeoHub project:

- source-authoritative semantic canvas design;
- guarded, revision-bound agent mutations;
- responsive interactive rendering plus isolated exact rendering.

It is a skills-only package. It runs no code, opens no network connections, collects no data, and requires no account or credential.
