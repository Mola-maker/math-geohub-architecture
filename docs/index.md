Portable Agent Skills for building trustworthy AI-native visual editors.

The plugin packages eight engineering capabilities derived from the public Math GeoHub project:

- source-authoritative semantic canvas design;
- guarded, revision-bound agent mutations;
- responsive interactive rendering plus isolated exact rendering;
- project-aware architecture, reuse, schema-drift, and migration review;
- authorization-aware verification and evidence reporting;
- reproducible multi-channel geometry research;
- bounded production search gateways with provenance and admission;
- journey-based accessibility, recovery, responsive, and performance audits.

It is a skills-only package. It runs no bundled code, collects no data, and requires no account or credential. The research skill can direct an AI client to use search connectors that the user has separately configured and authorized.
