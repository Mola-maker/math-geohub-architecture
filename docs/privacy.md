Last updated: August 30, 2026.

Math GeoHub Architecture is a static, skills-only plugin. The published package contains written instructions and reference documents only. It includes no executable scripts, MCP server, analytics, telemetry, account system, credential handling, cookies, or bundled network integration.

The `research-geometry-evidence` skill may instruct an AI client to use GitHub, Consensus, Exa, Tavily, or another search connector only when that connector is already available and the user's task calls for external research. Those services are configured and governed by the user's AI client; this plugin receives no credentials or search data.

The plugin itself does not collect, transmit, store, sell, or share personal data. Your chosen AI client may process prompts, files, and generated output under that client's own privacy policy and settings; this plugin does not change those controls.

If a future release adds a bundled service, executable component, authentication, or telemetry, this policy and the plugin version will be updated before release.

Privacy questions can be sent through the project [support page](support).
